# Chendong Xin CV

`main.tex` is the editable CV. In Overleaf, upload `CV_ChendongXin_Overleaf.zip` as a new project or replace the existing project's `main.tex`, then select **pdfLaTeX** and recompile.

The PDF served by the website is `../assets/docs/CV_ChendongXin.pdf`. This local environment has no TeX compiler, so `build_preview.py` creates a visual preview with the same content and geometry. It uses Times as a stand-in for the Computer Modern font used by `main.tex`; check the final line breaks and spacing after recompiling in Overleaf.
